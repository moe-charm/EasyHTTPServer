# Legacy EasyHTTPServer source archive

このディレクトリは、作者charmpicが2005～2006年に作成したEasyHTTPServer 1.2系の旧ソースを、設計史の資料として保存します。現代のネットワークへ公開して使用する製品コードではありません。

## 公開範囲

- `source-1.2/`: Visual C# Express 2005へ移行したC# / Windows Formsソース、resx、プロジェクト資料。
- `source-1.2/Backup/`: 当時の作業フォルダーにあったバックアップ。14ファイルは親の同名ファイルと同一ですが、5ファイルに差分があるため保存しています。

次はこの公開リポジトリへ含めません。

- 2005年の旧配布EXEと同梱DLL
- `TTFA*.dll`を含む旧バイナリ
- 旧ビルド出力、実使用設定、パスワード一覧、ログ

旧配布物は作者のローカル完全版で保存しています。主要ファイルの来歴とSHA-256記録は[旧版インベントリ](../docs/legacy-inventory.md)を参照してください。

## 安全上の注意

旧ソースには、path traversal、CGI実行、平文Basic認証、独自HTTP解析、Range処理など、現在の基準では危険な実装が含まれます。ビルドに必要だった旧DLLも同梱していないため、このディレクトリを実行可能な製品として提供していません。現在利用する実装はルートの`src/`を参照してください。

## 権利

旧ソースと旧TTFAライブラリはcharmpicが作成したものです。ただし、この公開リポジトリのMIT許諾は現代版`src/`、`tests/`と現代版文書を対象とし、`legacy/`は当時の通知を維持する歴史資料として扱います。
