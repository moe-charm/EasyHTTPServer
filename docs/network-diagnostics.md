# Network diagnostics

EasyHTTPServer 2は、旧版の「URL取得」を外部公開機能ではなく、利用者が明示的に実行するネットワーク診断として再設計します。

## グローバルIP確認

- 「確認する」を押した場合だけ、AWSの公開IP確認サービス`https://checkip.amazonaws.com/`へHTTPS GETを送ります。
- 送信される主な情報は通常のHTTPS接続に伴う送信元IP、TLS・HTTPメタデータです。共有フォルダー、アクセスコード、証明書、転送履歴は送信しません。
- 証明書はOS標準の検証を使います。証明書エラーを無視せず、HTTPへのリダイレクトも許可しません。
- 5秒でタイムアウトし、成功応答は最大128 byte、IPv4アドレス1件だけを受理します。
- 取得失敗はサーバーの開始・停止やファイル転送へ影響させません。
- 結果は画面表示とクリップボードへのコピーにだけ使い、設定やログへ保存しません。

## セキュリティ境界

表示される値は「AWSから見えた、このHTTPS接続の送信元IPv4」です。次のいずれも保証しません。

- インターネットからEasyHTTPServer 2へ到達できること
- ルーターのポート転送が設定済みであること
- CGNAT、二重NAT、VPN、プロキシが存在しないこと
- 表示したIPが固定されていること

本機能はUPnP、NAT-PMP、PCP、Windows Firewall、ルーター設定を変更しません。また、取得したIPから外部公開URLを自動生成しません。

## 実装境界

- UIは`IPublicIpResolver`だけへ依存し、問い合わせ先とHTTP処理をViewModelから分離します。
- 問い合わせ先を将来変更できる構造にしますが、初期版はAWSだけを利用し、複数事業者へ同時送信しません。
- テストでは偽のHTTPハンドラーまたは偽のResolverを使い、外部サービスへ接続しません。
